# TutoriaInteligente

Proyecto base para un sistema web con Flask y MariaDB.

## Configuración

1. Asegúrate de tener MariaDB instalado y ejecutándose.
2. Crea una base de datos llamada `tutoria_db` (o cambia el nombre en .env).
3. Actualiza las variables en `.env` con tus credenciales de MariaDB.
4. Instala las dependencias: `pip install -r requirements.txt`
5. Ejecuta la aplicación: `python app.py`

## Endpoints

- `/`: Página de inicio
- `/test-db`: Prueba de conexión a la base de datos
